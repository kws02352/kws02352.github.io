모바일/서버 환경에서 신분증·카드를 인식하는 ROI Detection 모델을 단독 개발하고, 다수 금융권 고객사 서비스에 탑재되어 약 3년간 운영한 라이브 모델입니다. 학습된 모델은 ONNX로 변환해 엔진 측에 전달하는 방식으로 배포되며, 신규 카드 추가·실패 케이스 대응·정확도 개선을 지속적으로 반영했습니다. 이 모델의 핵심인 다중 채널 ROI 식별 방법은 특허로 등록되어 있습니다.

정확도 98.9%ROI Score 0.9666 추론 속도 20% 향상모델 크기 1.1MB특허 등록

PROBLEM & SOLUTION
기존 OpenCV 파이프라인의 구조적 한계
기존 방식은 가이드박스 환경에서만 동작. 서버 환경에서는 카드가 자유 위치/크기로 들어와서 회전 정보도 못 잡았고, 0/90/180/270도를 각각 추론해야 하는 비효율이 있었음.
→ SOLUTION
  • 3채널 출력 설계: 카드 마스크(ch0) · 타이틀+회전(ch1) · 꼭지점 키포인트(ch2)
  • 위치 탐지와 회전 예측을 하나의 추론으로 통합한 1-Stage Detection 구조로 전환 → 추론 속도 20% 향상
  • ONNX 4스레드 기준 100ms 이하, 모델 크기 1.1MB로 저가형 안드로이드에도 탑재 가능
On-Device 리소스 제약 — 경량화와 정확도 유지
모바일 배포 요건상 엄격한 모델 크기·속도 제약. 단순 경량화하면 특징 추출 능력이 떨어짐.
→ SOLUTION
  • SE-Module를 적용한 Mobile-friendly 아키텍처로 경량화 시 성능 손실 최소화
  • 입력 이미지 크기 최적화 + Attention 메커니즘으로 카드 외곽선 같은 중요 특징에 집중
학습·평가 데이터 분포 불일치 — 실환경 일반화 저하
16만 장 전수 분석 결과 Contrast, Saturation, Blur, AreaRatio 등 통계적 갭 확인. 특히 Saturation이 2배 이상 차이 나는 게 가장 큰 원인.
→ SOLUTION
  • Augmentation 파라미터를 실제 촬영 환경에 맞게 전면 재설계해 분포 불일치 해소
클래스 확장(8→11종) 후 ROI Score 하락
8클래스 CNN 0.9633 → 11클래스 확장 후 0.9410으로 하락. CNN으로는 클래스 간 구분이 한계.
→ SOLUTION
  • CNN+Area Attention 먼저 시도했으나 효과가 작아서 ViT 백본으로 전환 → global feature 활용으로 클래스 구분 성능 회복
  • Attention은 Area Attention(행/열 단위 지역 패턴)과 Global Attention(전역 문맥)을 조합 설계
  • Loss 전면 재설계: MSE+CE → OHEM+Focal, Dice, IoU, Distance-Transform Boundary Loss
  • LossWeightScheduler + ModelEMA 도입
  • 데이터 개편과 Loss 개편을 함께 가져가 ROI Score 0.9666 회복 (확장 전 최고치 0.9633 초과)
ROI 탐지·카드 분류 중복 연산
Regression(ROI 탐지)과 Classification(카드 종류)을 별도 모델로 처리하면서 중복 연산 발생.
→ SOLUTION
  • Multi-task Learning 구조로 두 과업을 하나의 모델에서 동시 학습·예측
  • Seg-Guided Pool: 카드 마스크 채널을 분류 헤드의 공간 어텐션 가중치로 활용 → 두 태스크 상호 보완
운영 사이클 — 라이브 모델 지속 업데이트
상용 이후에도 신규 카드 종류 추가, 고객사 실패 케이스 대응, 정확도 개선이 계속 필요한 상황.
→ OPERATION
  • 데이터 수집 → 분석 → 재학습 → ONNX 재변환 사이클 직접 담당
  • 약 3년간 사이클을 유지하면서 정확도와 커버리지를 지속적으로 개선
