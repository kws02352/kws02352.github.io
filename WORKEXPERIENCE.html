2.1.1. 3채널 마스크 1-Stage 구조 (특허 등록)

문제

  • 기존 OpenCV 방식은 화면의 가이드 박스 안에 맞춰 찍은 이미지에서만 동작해, 서버로 들어오는 자유로운 위치와 크기의 이미지에 대응하지 못함
  • 카드의 회전 각도를 알 수 없어 0/90/180/270도를 모두 입력해 인식해야 했고, 추론 횟수가 4배로 늘어남
  • 위아래 방향을 몰라 타이틀 영역을 따로 분석해 좌상단을 찾는 추가 처리가 필요

과정

  • 영역 검출, 꼭지점 좌표, 방향 판별을 한 번의 추론으로 해결하도록 3채널 마스크를 출력하는 1-Stage 구조 설계
    • 카드 영역 채널: 카드 전체 영역 마스크. erode/dilate 후처리로 꼭지점 후보 추출
    • 타이틀 영역 채널: 카드 상단 타이틀 위치로 좌상단을 판별해 회전 방향을 함께 결정
    • 꼭지점 채널: 가장 밝은 점을 코너로 쓰고, 카드 영역 채널의 좌표와 매칭해 정밀한 4점 추출

성과

  • 4방향 반복 추론을 단일 추론으로 통합(추론 4회에서 1회), 가이드 박스 없이 촬영한 이미지도 처리
  • 특허 등록: 타겟 이미지를 식별하는 방법 및 장치 (제10-2837662호)

2.1.2. 클래스 확장과 성능 회복

문제

  • 지원하는 신분증과 카드 종류가 늘면서 클래스를 5종에서 8종, 11종으로 확장해야 했음
  • 11종으로 늘리자 ROI Score가 0.9633에서 0.9410으로 하락. 로컬 특성에 의존하는 CNN 백본으로는 비슷하게 생긴 카드 간 구분에 한계가 있다고 판단

과정

  • CNN 백본을 TinyViT로 교체하고, 인코더에는 행/열을 번갈아 쌓은 Area Attention, 디코더에는 Linear Attention을 적용해 모바일 속도 제약 안에서 전역 특징을 활용
  • 카드 영역 마스크로 특징을 풀링해 카드 종류를 분류하는 헤드(Seg-Guided Pool) 추가. 학습 보조용이 아니라 추론에서도 쓰는 헤드로, 늘어난 클래스 간 구분을 보강
  • 처음 판단과 달리 백본 교체만으로는 기대한 성능이 나오지 않음. 원인을 다시 찾다가 적용돼 있던 Augmentation 설정이 실제 촬영 환경과 어긋나 있는 것을 확인하고, 실촬영 조건에 맞춰 재설계
  • 기존 Loss는 마스크에 MSE, 분류에 Cross Entropy만 쓰는 구조라 경계 정밀도와 어려운 샘플을 다루지 못했고, ViT 전환 후 경계가 흐릿해지는 문제가 두드러짐. OHEM+Focal(배경 픽셀이 대부분인 클래스 불균형, 어려운 픽셀 집중), Dice(영역 겹침), Distance-Transform Boundary Loss(경계 정밀도)로 재설계하고 LossWeightScheduler와 ModelEMA 도입
  • 구조, 데이터, Loss를 함께 바꿨고 단계별 기여는 따로 기록해 두지 않아, 성과는 세 가지를 함께 적용한 결과로만 적음

성과

  • ROI Score 0.9410에서 0.9666으로 회복, 확장 전 최고치(0.9633) 초과
  • 5종, 8종, 11종으로 확장할 때마다 성능을 개선해 재배포

2.2.1. 베이스 모델 선정

2.2.2. 합성 학습 데이터 파이프라인 (특허 출원)

문제

  • 양식마다 HTML을 손으로 짜는 방식은 양식이 늘어날수록 확장이 불가능

과정

  • 빈 양식에는 레이아웃과 필드 구조가 모두 들어 있다는 점에 착안해, 구조는 양식에서, 내용은 형식을 지킨 랜덤 값으로 채우는 파이프라인 설계
    1. 고객사가 제공한 빈 양식을 이미지화
    2. GPT로 양식의 HTML 레이아웃 구조를 추출해 렌더링
    3. 각 입력 칸 좌표에 필드 형식(날짜, 금액 등)을 지킨 랜덤 값을 주입
    4. 배경 합성, Perspective 변환, Augmentation으로 실제 촬영 문서처럼 변형

성과

  • 실제 고객 문서 없이 합성 학습 데이터 약 4.7만 건 생성
  • 특허 출원: 합성 문서 생성 방법 및 시스템 (10-2026-0032723)

2.2.3. 검증 설계와 결과

과정

  • Stable Diffusion XL에 사용자 사진 3~5장을 LoRA로 파인튜닝해 아이덴티티 주입(학습 약 15분)
  • 처음에는 모델 구조와 학습 파라미터 튜닝에 집중했지만 아이덴티티가 흔들리는 문제가 반복됨. 원인은 모델이 아니라 입력 사진의 각도와 표정 편차였고, 오픈소스 Mean Face와 Frontalization으로 입력을 정면 기준으로 정규화
  • 안경 쓴 사진이 섞이면 생성 결과의 콧등에 검은 자국이 생겨, 오픈소스 안경 제거 모델을 학습 전처리에 추가
  • 여성 대비 남성 프로필 품질이 낮아 남성 특화 프롬프트를 반복 실험. 의상은 프롬프트만으로 제어하기 어려워 안정적으로 제어되는 옵션만 알파에 포함
  • 닮은 정도를 유사도 지표로 재 봤지만 수치와 육안 판단이 어긋나는 경우가 있어 지표를 신뢰하기 어려웠고, 내부 반복 피드백과 육안 검수를 주된 평가 방식으로 삼음

성과

  • 모델을 바꾸지 않고 입력 정규화만으로 아이덴티티 일관성 확보
  • 안경 아티팩트 제거로 생성 품질 편차 감소, 알파 버전 출시

2.4. 서울아산병원 (SVV 예측 모델)

수술 중 동맥혈압(ABP) 신호로 SVV(Stroke Volume Variation)를 10초 단위로 예측하는 모델 개발

  • 역할: AI 연구원(계약직), 데이터 정제부터 모델 설계까지 담당
  • Skills: Python, PyTorch, Signal Processing

문제

  • 수술실에서 수집한 ABP 신호에 노이즈가 많고, 학습에 쓸 수 있는 데이터가 부족

과정

  • 노이즈 원인을 찾으려고 수술실을 직접 관찰하고 담당 의사에게 자문. 주파수 필터링과 Gradient 임계값 규칙으로 클렌징
  • "ABP 파형 그림만 봐도 SVV 감이 온다"는 전문의 인터뷰를 근거로, 시계열 모델 대신 파형의 형태를 보는 CNN으로 재설계
  • 1D 시계열을 원본, Slope, FFT 3채널로 바꾸고, 성격이 다른 채널을 따로 처리하도록 Separable Conv 적용
  • Sliding Window(2초 이동)로 학습 샘플 확장

성과

  • 예측 오차(MSE) 20.25에서 9.8로 51.6% 감소
